# 14. Entregables y publicación en GitHub

## Video

Video demostrado: [https://youtu.be/XtP_YsM0tjs](https://youtu.be/XtP_YsM0tjs)

La rúbrica exige duración máxima de diez minutos, fecha y hora visibles, rostro visible y voz audible. El video se coloca al inicio de `README.md` y `README_EN.md` para que sea el primer elemento que encuentra quien visita el repositorio.

## Repositorio

Nombre sugerido:

```text
fortigate-sslvpn-jumpserver-remoteapp-lab
```

Título de presentación:

```text
FortiGate SSL-VPN, Jump Server & Role-Based RemoteApp
```

Pasos de publicación:

1. Crea el repositorio de GitHub con el slug sugerido.
2. Descomprime el ZIP manteniendo la estructura de directorios.
3. Sustituye los diez marcadores de `images/` con capturas reales.
4. Completa las exportaciones finales de configuración en `running-configs/` y sanitiza secretos.
5. Revisa que README y documentos se rendericen en GitHub.
6. Copia la URL final del repositorio en el TXT de entrega.
7. Revisa que el video de YouTube sea accesible y el enlace correcto.

## TXT académico

El archivo `ENTREGA_FredCastillo_20252175_P4.txt` incluye el enlace del video y una línea para la URL definitiva del repositorio. Antes de entregar, sustituye el marcador por el enlace final del repo y comprueba el nombre de archivo conforme a la rúbrica: `FredCastillo_20252175_P4.txt`.

## Calidad de la documentación

- Documenta el propósito del laboratorio, arquitectura, direccionamiento y servicios.
- Incluye diagramas y un máximo de diez capturas.
- Guarda scripts utilizados y explica dónde se ejecutan.
- Añade running-configs reales, finales y sanitizados.
- Evita subir credenciales, certificados privados o datos de autenticación.
