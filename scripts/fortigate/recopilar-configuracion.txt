FORTIGATE — recopilación por GUI/consulta

La rúbrica requiere realizar y demostrar la configuración de FortiGate mediante GUI. Utiliza GUI para modificar interfaces, objetos, SSL-VPN, políticas y logging. Para guardar evidencia textual puedes ejecutar comandos de lectura en la CLI desde consola/GUI:

get system status
show system interface
show router static
show firewall address
show firewall addrgrp
show firewall service custom
show firewall vip
show firewall policy
show vpn ssl settings
show vpn ssl web portal
show user group

Registra el hostname y fecha de recopilación. No publiques contraseñas, PSK, tokens, claves privadas, certificados PFX, hashes sensibles o backups binarios sin revisar.
